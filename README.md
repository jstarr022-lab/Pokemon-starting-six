# Pokémon Starting Six

Draft a starting six of LW, C, RW, LD, RD, and G from the original 150 Pokémon, play an 82-game season, and chase the Cup.

Play it live: https://jstarr022-lab.github.io/Pokemon-starting-six/

Sprites and data come from PokéAPI. This is a fan project and is not affiliated with Nintendo, Game Freak, The Pokémon Company, or the NHL.
